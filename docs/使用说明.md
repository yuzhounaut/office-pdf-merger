# Office 资料一键合并 PDF v1.4.3

本版在 v1.4.2 基础上进行了以下关键问题修复与体验优化：

1. **修复文件名带点截断问题**：
   - 彻底修复了输出文件名中包含版本号、序号或日期点号（如 `18.1-杨某某（CV、GCP、执业证书）`）时，因系统将点号后内容误当做扩展名导致名称被截断只剩前两个字的问题。
   - 现在支持完整保留用户输入的各类点号命名；若手动输入包含 `.pdf` 扩展名亦能智能适配。

2. **清单与日志迁移至程序目录 `OfficePdfData`**：
   - 生成的 `.清单.csv` 和 `.日志.txt` 不再输出到用户的目标输出文件夹，统一收纳于程序所在目录下的 `OfficePdfData` 文件夹中。
   - 保证最终输出文件夹整洁，仅存放合并生成的 PDF 文件（以及勾选另存每组时的子目录）。

### 使用说明

1. 完整解压文件夹，保留主程序、`OfficePdfWorker.exe` 和 `qpdf` 文件夹。
2. 打开 `Office资料一键合并PDF_v1.4.3.exe`，加入 Word、PPT、图片或 PDF，调整顺序并生成 PDF。
3. Word/PPT 需要本机安装 Microsoft Office；图片/PDF 不需要。qpdf 已随附，不用额外下载。
4. 后台程序不需要单独打开。关闭主窗口后已启动的任务继续，重新打开可查看或取消；退出 Windows 或结束工作进程会中断任务。已有输出自动另存，不覆盖源文件。
5. 任务清单和日志自动保存在程序目录下的 `OfficePdfData` 文件夹中，方便追溯和对账。
